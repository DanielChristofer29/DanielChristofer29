### Sobre mim

Sou desenvolvedor em formação e uso projetos acadêmicos para transformar teoria em aplicações funcionais.

- Desenvolvo aplicações backend com **Node.js, Express e PostgreSQL**.
- Pratico **orientação a objetos com Python e Pygame**.
- Busco evoluir em código limpo, testes automatizados, persistência de dados e Git.
- Gosto de revisar projetos antigos e transformá-los em trabalhos mais completos para portfólio.
